글자를 몰라도, 발음이 서툴러도, 궁금한 그 순간에 말로.

## 🤔 왜 '모야, 모야?' 인가요

아이는 하루에도 몇 번씩 "그게 뭐야?"를 묻습니다.
어른들의 대화, 그림책, 길에서 본 간판 속에서 낯선 단어를 만나니까요.

우리는 보호자 37명, 교사 6명을 만났습니다.

<table>
<tr><td align="center"><b>37명 중 33명</b></td><td>보호자가 지난주에 아이에게 단어 질문을 받았어요</td></tr>
<tr><td align="center"><b>76%</b></td><td>아이에게 가장 편한 질문 방법은 '말하기'였어요</td></tr>
<tr><td align="center"><b>81%</b></td><td>보호자가 가장 어려워하는 건 아이 눈높이로 설명하기였어요</td></tr>
<tr><td align="center"><b>6명 중 5명</b></td><td>교사는 나중에 답하면 아이가 질문을 잊는다고 했어요</td></tr>
</table>

질문은 많은데, **답을 듣는 순간**에서 막힙니다.
바로 설명하기는 어렵고, 설명해도 아이가 이해했는지 알기 어렵고, 미루면 잊힙니다.
음성 검색에 맡겨 봐도 서툰 아이 발음은 자주 놓치고요.

> 그래서 질문했습니다.
> **서툴게 물어도, 그 자리에서 이해할 수 있다면?**

<br/>

## 👽 모야가 하는 일

**모야, 모야?** 는 **아이 모드**와 **보호자 모드**로 나뉘어요.

### 👧 아이는 묻고, 따라 하고, 모아요

> 🎙️ **말로 질문** → 🔎 **후보 고르기** → 💬 **쉬운 설명** → 🗣️ **따라 말하기** → 🌟 **스티커 · 단어 카드** → 🎵 **나만의 노래**

마이크를 누르고 궁금한 단어를 말하면, 모야가 아이 발음에 맞춰 찾은 후보 중에서 아이가 직접 골라요.
나이에 맞는 설명을 듣고 직접 따라 말하면 스티커와 단어 카드, 노래 쿠폰을 받아요.
새 단어로 쿠폰이 5장 모이면, 그 단어들로 나만의 노래가 만들어져요.

### 👨‍👩‍👧 보호자는 곁에서 이어 받아요

> 🔐 **PIN 잠금** · 🧒 **다자녀 프로필** · 📋 **질문 기록** · 🗂️ **물어볼 단어** · 📊 **주간 리포트**

PIN으로 분리된 공간에서, 아이별 연령대와 모야 캐릭터를 정하고 질문 기록을 확인해요.
모야가 끝내 알아듣지 못한 질문은 버려지지 않고 **물어볼 단어**로 남아요. 보호자는 아이의 원본 음성을 듣고 올바른 단어를 입력해 직접 풀어 줄 수 있어요.
매주 자동으로 만들어지는 리포트에서는 아이가 무엇을 궁금해했고 **실제로 어떻게 발음했는지**, 그리고 함께 나눌 대화 주제까지 볼 수 있어요.

<details>
<summary><b>🔁 한 번에 단정하지 않아요 — 모야의 되묻기</b></summary>

<br/>

음성 인식 결과 하나로 정답을 단정하지 않고, 아이에게 묻고 문맥을 더해 아이의 의도를 찾아가요.

```
👧  "모야, 영꼬가 뭐야?"
👽  "이 중에 뭐가 궁금해?  ① 연고  ② 연기  ③ 영어"     ← 1차: 발음 중심, 최대 3개
👧  "아니야!"
👽  "어디서 들었어?"
👧  "엄마가 다쳤을 때 발라 줬어"
👽  "그럼 이거야?  ① 연고  ..."                         ← 2차: 발음 + 문맥으로 넓게
```

- **1차 탐색** — 아이 발음 자체를 중심으로, 최소 발음 유사도 0.60 이상인 후보를 최대 3개까지 보여 줘요
- **2차 탐색** — 더 넓은 발음 변형과 함께, 질문 문장과 아이가 단어를 들은 상황을 반영해 다시 찾아요
- **그래도 못 찾았다면** — 억지로 답하지 않고 **물어볼 단어**로 보호자에게 넘겨요
- **뜻이 여러 개라면** — 동음이의어·다의어는 아이가 원하는 뜻을 직접 골라요

</details>

<details>
<summary><b>🔎 아이 발음에 특화된 단어 탐색 알고리즘</b></summary>

<br/>

일반적인 문자열 비교로는 아이 발음과 STT 인식 오류를 함께 다루기 어려워요. 그래서 발음 탐색은 자체 알고리즘이 맡아요.

- 한글을 **초성 · 중성 · 종성** 단위로 분해하고, 가중치를 준 **레벤슈타인 거리**로 비교해요
- 받침 탈락, 자음 대치, 모음 혼동 등 **아동 발음 변형 규칙 24개**를 반영해요
- 정답에서 아이 발음 쪽으로 바꿔 보는 **정방향**, 아이 발음에서 원래 단어를 거슬러 찾는 **역방향** 탐색을 함께 써요
- 질문 문장에서 호칭 · 조사 · 질문 표현을 걸러 내고, 아이가 **진짜 궁금해하는 단어**만 뽑아요

LLM 은 필요한 곳에만 써요. 문맥 데이터가 없는 외부 사전 단어를 평가할 때만, 그리고 **실제 사전에서 검증된 후보만** 평가하도록 했어요. LLM 호출이 실패해도 발음 점수만으로 탐색은 계속돼요.

</details>

<details>
<summary><b>📚 쓸수록 넓어지는 단어</b></summary>

<br/>

- 직접 검수한 **119개 단어**는 들은 곳 · 힌트 · 예문 같은 메타데이터와 연령별 설명을 갖고 있어요
- 그 밖의 단어는 **표준국어대사전**과 연동해 찾고, 사전 정의를 바탕으로 연령별 (3~4세 / 5세 이상) 쉬운 설명을 만들어요
- 아이가 확정한 새 단어는 공통 단어 데이터로 저장돼서, 다른 아이가 같은 단어를 물으면 설명과 음성을 **그대로 재사용**해요
- 사전 원본 정의와 AI 가 만든 설명은 **구분해서 저장**해요

</details>

## 🧭 질문이 노래가 되기까지

```
🎙️ 말로 질문         말이 끝나고 1.5초 조용하면 녹음이 스스로 멈춰요
   │
   ▼
📝 단어 추출         CLOVA Speech로 듣고, 호칭·조사·질문 표현을 걸러 궁금한 단어만
   │
   ▼
🔎 후보 찾기         자모 유사도 + 아동 발음 변형 규칙 24개 → 최대 3개 후보
   │
   ▼
🔁 되묻기            아니면 들은 상황까지 더해 2차 탐색 · 끝내 모르면 '물어볼 단어'로
   │
   ▼
📖 쉬운 설명         검수 단어 119개 + 표준국어대사전 → 연령별 설명
   │
   ▼
🔊 모야의 목소리     Google Cloud TTS + Parselmouth · Praat로 피치·포먼트·억양 후처리
   │
   ▼
🗣️ 따라 말하기       연령별 발음 특성을 반영해 판정 → 스티커 · 단어 카드 · 노래 쿠폰
   │
   ▼
🎵 단어 노래         쿠폰 5장이 모이면 학습 단어 5개로 개인화 노래를 비동기 생성
   │
   ▼
📊 주간 리포트       스케줄러가 매주 자동 생성 · 스냅샷으로 지난 리포트도 보관
```
